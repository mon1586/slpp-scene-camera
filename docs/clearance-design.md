# カメラ候補の可視性評価

状態: **アンカーLOSによる動的A/D候補を実装・自動テスト・DLLビルド済み／ゲーム内確認待ち**

## 要件

- 各プリセットからアンカーへの見通しを判定し、A/Dで選べる候補を更新する。
- キャラクターのcollisionに影響されず、背景や家具など環境の遮蔽物を判定できる。
- 使用可能なプリセットについて、中心と四隅のLOS条件を満たすことを確認できる。
- シーン内で構図が変化した場合は、現在の見え方に基づいて判定を更新できる。
- 使用可否の変化だけでは現在のプリセットを切り替えず、カメラ制御も解放しない。
- プリセットを使用できない理由を確認できる。

## 詳細設計

デバッグ表示は[`debug.md`](debug.md)に記載する。

- シーンアンカーとプリセットから、評価対象となるカメラ候補の位置と向きを生成する。
- 各候補カメラを中心とし、その右・上方向に揃えた固定32×18の長方形の中心と四隅から、平滑化後のアンカーの一点へ合計5本のLOSを調べる。
- 他の参加者の身体中心の可視性は使用可否の条件にしない。
- シーン参加者かどうかにかかわらず、キャラクターのcollisionは遮蔽物として扱わない。
- 屋外の地形も環境の遮蔽物として扱う。地中のカメラ候補から地上のアンカーへ地表を横切るLOSは、地表の裏側から見ている場合も遮蔽とする。
- 中心が可視で、四隅のうち3本以上が可視の場合に使用可能とする。中心遮蔽または四隅2本以上遮蔽なら使用不能とする。
- カメラ姿勢または5本すべての有効な判定を取得できない場合は使用不能とする。環境collision内から始まるrayは遮られたものとして扱う。
- シーン開始時は最初の使用可能候補を初期選択する。初期選択できなかった場合は通常カメラを維持する。
- 通常・デバッグモードとも0.5秒ごとに全候補を再評価する。アニメーション変更後と編集終了時にも再評価する。
- 再評価で現在の候補が使用不能になっても、その選択とアンカーへの追従を維持する。全候補使用不能でも自動切り替えや自動解放を行わない。
- A/Dは現在の選択を起点に、最新の使用可能候補だけを保存順の前後へ循環する。候補が0件なら何も変更しない。復帰した候補はA/Dの選択肢へ戻す。
- 初期選択ができなかった後に候補が復帰しても自動取得しない。選択なしでDを押すと最初、Aを押すと最後の使用可能候補を選ぶ。
- 編集終了時は明示的に編集したプリセットを使用不能でも維持できる。以後A/Dでは最新の使用可能候補へ進む。
- 未保存の新規編集を閉じた場合は編集前の選択へ戻す。編集前の選択がない、または削除済みなら通常カメラへ戻り、別候補を自動選択しない。
- ポーズ中、編集中、アンカー入力欠落中は定期評価を進めない。欠落中は古い評価によるA/D切り替えを止め、入力復帰時は再評価してから選択を再開する。
- 遅れた更新をまとめて実行せず、一更新あたりの全候補評価は最大1回とする。
- アニメーション変更後の再評価を待つ間は、定期評価とA/Dを停止する。固定時間を待たず、入力を取得できた最初の更新で一度評価する。定期評価の期限も重なっていた場合は重ねて評価せず、次の0.5秒をこの評価から数える。

デバッグモードの使用可否表示にも同じ条件を使う。デバッグのA/Dは使用可否で除外せず、遮蔽・判定不能を含む全候補を保存順に循環する。現在の表示対象が使用不能になっても自動では変更しない。計測条件と指標は[`debug.md`](debug.md)に従う。

## 初期対象に含めないもの

- カメラ候補位置の周囲にある空間の広さ。
- 現在のカメラ位置から候補位置までの移動経路。
- 可視結果に合わせたカメラ候補位置の自動補正。
- キャラクター同士の画面上の重なりによる見え方の評価。
- キャラクターcollisionと薄い環境collisionがほぼ同じ位置で重なる境界の判定保証。

## 確認項目

- 中心が見え、四隅の遮蔽が0本・1本なら使用可能、2本・3本・4本なら使用不能になる。
- 中心だけ遮られた場合は、四隅が見えていても使用不能になる。
- 一点でも判定不能または欠落なら使用不能になる。
- シーン参加者または第三者のキャラクターが評価経路と重なっても、そのキャラクターによって身体中心が遮られたとは判定しない。
- 複数のキャラクターが評価経路と重なっても、すべてのキャラクターを透過して評価を継続する。
- キャラクターを透過した先に壁や家具がある場合、そのキャラクターではなく壁や家具によって身体中心が遮られたと判定する。
- 壁や家具などキャラクター以外の遮蔽物が評価経路を塞いだ場合、身体中心が遮られたと判定する。
- 屋外でアンカーが地上にあり、候補カメラの中心が地中にある場合は、地表による中心遮蔽としてその候補を使用不能にする。
- 屋外で中心と四隅からアンカーまでの経路がすべて地表の上にあり、他の遮蔽物もない場合は使用可能になる。
- 地表の裏側による遮蔽でも、デバッグ表示の衝突位置は地表上にあり、衝突までの割合は候補カメラ側の判定開始点を基準とする。
- 地表を横切る経路にキャラクターが重なっても、キャラクターを除外したうえで地表による遮蔽を判定する。
- 評価全体について、キャラクターcollisionを透過するために行った分を含む物理ray query数を確認できる。
- シーン開始時、アニメーション変更後、および編集終了後に保存済み構図へ戻るとき、全候補を評価し直す。
- 通常モードでは、再評価で全候補が使用不能になっても現在の選択を維持し、A/Dを押しても変更しない。復帰した候補へはA/Dで移れる。
- シーン終了、ロード、新規ゲーム、reset後に以前の評価結果を使用しない。
