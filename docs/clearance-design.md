# カメラ候補の可視性評価

状態: **可視性評価・キャラクターcollision透過の主要経路をゲーム内確認済み／境界ケース確認待ち**

## 要件

- 各プリセットが、すべてのシーン参加者を遮蔽物越しではなく映せるか判定できる。
- キャラクターのcollisionに影響されず、背景や家具など環境の遮蔽物を判定できる。
- 使用可能なプリセット同士で、参加者の見え方の品質を比較できる。
- シーン内で構図が変化した場合は、現在の見え方に基づいて判定を更新できる。
- いずれかの参加者を映せないプリセットを使用せず、使用可能なプリセットがなければ通常のカメラへ戻せる。
- プリセットを使用できない理由を確認できる。

## 詳細設計

デバッグ表示は[`debug.md`](debug.md)に記載する。

- シーンアンカーとプリセットから、評価対象となるカメラ候補の位置と向きを生成する。
- 各参加者の顔、胸、腰を、その参加者の見え方を代表する評価点とする。
- 各カメラ候補から各評価点までの間に遮蔽物があるかを調べ、参加者および評価点ごとの可視結果を作る。
- シーン参加者かどうかにかかわらず、キャラクターのcollisionは遮蔽物として扱わない。
- キャラクター以外のcollisionがカメラ候補と評価点の間にある場合は、評価点が遮られているとする。
- 一つ以上の評価点が見える参加者を、そのカメラ候補から映せる参加者とする。
- 映せない参加者が一人でもいるカメラ候補は、使用可能な候補から除外する。
- 使用可能な候補には、見える評価点の内訳を可視品質として付与する。
- シーン開始時とアニメーション変更後に、現在の参加者の姿勢から評価点を取得し直して全候補を再評価する。
- 使用可能な候補がなくなった場合は、適用中の候補を維持せず通常のカメラへ戻す。

## 初期対象に含めないもの

- カメラ候補位置の周囲にある空間の広さ。
- 現在のカメラ位置から候補位置までの移動経路。
- 可視結果に合わせたカメラ候補位置の自動補正。
- キャラクター同士の画面上の重なりによる見え方の評価。
- キャラクターcollisionと薄い環境collisionがほぼ同じ位置で重なる境界の判定保証。

## 確認項目

- 一人の参加者について顔、胸、腰のいずれか一つ以上が見える場合、その参加者を映せると判定する。
- 一人でもすべての評価点が遮られた参加者がいる場合、その候補を使用不可と判定する。
- すべての参加者を映せる候補について、見える評価点の数と部位を比較できる。
- 評価点または判定を取得できない場合、それを見える結果として扱わない。
- シーン参加者または第三者のキャラクターが評価経路と重なっても、そのキャラクターによって評価点が遮られたとは判定しない。
- 複数のキャラクターが評価経路と重なっても、すべてのキャラクターを透過して評価を継続する。
- キャラクターを透過した先に壁や家具がある場合、そのキャラクターではなく壁や家具によって評価点が遮られたと判定する。
- 壁や家具などキャラクター以外の遮蔽物が評価経路を塞いだ場合、評価点が遮られたと判定する。
- 評価全体について、キャラクターcollisionを透過するために行った分を含む物理ray query数を確認できる。
- シーン開始時とアニメーション変更後に全候補を評価し直す。
- 再評価によって使用可能な候補がなくなった場合、通常のカメラへ戻る。
- シーン終了、ロード、新規ゲーム、reset後に以前の評価結果を使用しない。
