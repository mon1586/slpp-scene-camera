# Move Scene対応

## 目的と到達状態

プレイヤー参加シーンのMove Scene中に、移動と視点操作を妨げない。移動の完了・取消後も同じシーンが続く場合は、現在位置に合わせたシーンカメラへ自動復帰する。

長押しと時間切れの双方で移動入力の許可・再制限を実測した。本対応は、Move Scene固有の開始通知を仮定せず、プレイヤーが移動できる間はSSCが制御を返す方針とする。主経路のゲーム内結果と、未確認の組み合わせは [テスト記録](move-scene-test.md) に記載する。

## 中断・復帰の条件

- 対象は有効なプレイヤー参加シーン。シーン中に移動入力が許可されている間は、一時中断してカメラを返す。Move Scene以外の理由で移動が許可された場合も同じ扱いとし、移動許可をMove Scene固有の証明とは扱わない。
- 移動入力が再び制限され、対応カメラ状態かつポーズしていない場合は、返却完了と有効な身体情報を確認できた最初の更新で復帰する。再配置・アニメーション変更通知を理由に固定時間の待機を追加しない。
- 移動が再び許可された、ポーズした、または入力状態が取得できない場合は、復帰を保留する。時刻経過だけで復帰しない。
- 再配置成功通知がない場合も、再制限と非ポーズ状態の継続に基づいて復帰できる。これにより取消時の通知欠落だけでは中断が残留しない。
- 返却義務が残る間は中断を継続する。復帰時は現在の身体中心から新たに構図を評価し、最初の有効候補を選ぶ。候補なし・取得拒否は既存の失敗規則に従い、毎更新で取得を繰り返さない。
- 一時中断ではシーン識別情報と開始時刻を保持し、30分の上限を延長しない。中断中はポーズ中もメイン更新で返却と上限判定を進める。
- Free以外の対象外カメラ状態への移行、所有権喪失、ロード・resetなどの既存の終了条件は維持する。一時中断を理由に終了済みシーンを復活させない。
- 一時返却を試みた時点ですでに所有権を失っていた場合も、対象シーンを破棄する。正常に返却した後で別Modがカメラを所有することとは区別する。

## カメラの振る舞い

- Move Scene中はカメラとFOVを返し、追従・再取得・プリセット切り替え入力・Editorのpreviewで移動操作を妨げない。未保存確認で返却を遅らせない。
- 完了・取消後、同じシーンが継続し、有効な構図を準備できた場合は自動復帰する。移動前のワールド位置をそのまま表示しない。
- 移動中のシーン終了・ロード・新規ゲーム・resetは復帰予約を取り消す。遅れた移動関連通知で破棄済みのシーンを再開しない。
- 返却に失敗した場合は実行可能な機会に再試行する。返却完了前に再取得せず、他Modの所有権を奪わない。
- Debug中はカメラを取得しない。移動を理由にDebug設定を変更しない。
- 移動開始前に操作が取り消された場合は、通常のシーンカメラを継続する。

## 調査段階の観測条件

- 通知名にAnimationを含まないSexLab由来の通知も、引数・送信元とともに識別できる。
- プレイヤー参加シーンの開始以後、移動・視点・視点切り替え・戦闘の入力許可、カメラ状態、ポーズ、SSCが記録している所有状態の変化を確認できる。カメラの継続更新が止まっても観測を続ける。
- 同じ状態が続く間は状態ログを繰り返さない。シーン終了後の返却も観測し、ロード・新規ゲームでは観測区間を区切る。
- 観測のために入力許可、カメラ、外部Modの設定や通知の採否を変更しない。観測失敗だけを理由にシーンを終了しない。
- 記録されたSSCの所有状態と、外部APIで確認した実際の所有者は区別する。FOVの記録は状態変化時の値であり、連続したFOV計測ではない。

## 受入条件

| 操作 | 期待する結果 |
| --- | --- |
| Move Scene開始・移動・視点操作 | 移動と視点操作が支障なく行える |
| 移動の確定／時間切れによる再配置 | 同じシーンなら移動先に合わせて自動復帰する |
| 移動前の説明画面で取消 | シーンカメラを継続する |
| 再配置不可の画面で取消 | 同じシーンが継続するなら、その位置・姿勢に合わせて復帰する |
| Move Sceneの連続使用 | 毎回返却・復帰できる |
| 移動中のシーン終了・ロード・reset | カメラ・FOV・入力制御が残留せず、古い通知で復帰しない |
| 返却失敗・対象外カメラ状態 | 返却の再試行を続け、成功前に再取得しない |
| Debug／Editorとの競合 | 移動操作と安全な返却を優先し、Debug中は独自カメラを取得しない |

自動テストは検出後の状態遷移と返却義務を検証する。実際の検出タイミング、操作のしやすさ、SLPP・SmoothCamとの共存はゲーム内テストで確認する。
