# SKSE Menu カメラプリセット設定仕様

状態: **Preset dashboard・使用不可候補のpreview編集実装済み／自動テスト・DLLビルド済み／ゲーム内確認待ち**

## 目的

SKSE Menuのカメラプリセットeditorで、ユーザーが何を設定でき、その値を変えると構図がどう変わるかを定める。また、editorを利用できる条件と、scene終了、camera制御喪失、プリセット0件などの境界動作を定める。

この文書はユーザーに見える設定と振る舞いだけを扱う。保存ファイルの形式、座標計算、内部状態、API呼び出し、実装手順は扱わない。

## Editorへの導線

- SKSE Menu FrameworkのMod Control Panelに`Sexlab Scene Camera > Camera Presets`を表示する。
- `Camera Presets`ページはPreset dashboardとし、保存済みプリセットの一覧、現在のsceneでの可視状態、camera状態を、camera制御を変更せずに表示する。
- 各プリセットには、現在のsceneで使用可能、現在のsceneでは使用不可、未評価のいずれかを、色だけでなく文言と記号でも表示する。
- previewを開始できない場合は、プリセットの可視状態とは分けてcamera状態と理由を表示する。
- 評価済みプリセットには、見える参加者数と全参加者数、見える評価点数と評価可能な点数を表示する。
- 使用不可のプリセットには、camera poseを作れない、参加者を映せないなどの理由を表示する。
- Dashboardでプリセットを選択しても、ゲーム時間の停止またはcamera previewを開始しない。
- Dashboardには、可視判定のデバッグ表示だけを前後のプリセットへ切り替える操作を設けない。
- 選択したプリセットの`Preview & edit`を実行すると、ゲーム時間を停止してcamera previewを開始し、専用editorを表示する。
- プリセットが0件の場合は、`Create & preview preset`から標準初期値の新規プリセットをpreviewする。
- cameraを使った構図確認を開始できない状態では、previewを開始する操作を無効にして理由を表示する。一覧と状態の確認は妨げない。
- 保存済みプリセットのうち現在のsceneで使用可能なものがなくても、previewを開始可能なら使用不可のプリセットを選択してeditorへ進める。
- Improved Cameraがロードされている場合は非サポート構成としてeditorを無効にし、その理由を表示する。
- SKSE Menu Frameworkが利用できない場合も、保存済みプリセットを使う通常のscene camera機能には影響させない。

## 設定項目

Editorには次の5項目を表示する。

| 表示名 | 変更時の構図 |
|---|---|
| `Pan Right` | カメラと注視中心を画面の左右方向へ移動する |
| `Pan Up` | カメラと注視中心を画面の上下方向へ移動する |
| `Yaw` | アンカーの周囲を水平方向に周回する |
| `Pitch` | アンカーの周囲を垂直方向に周回する |
| `Distance` | 注視方向を維持したまま、注視中心へ寄る、または離れる |

### Pan Right

- 常に現在の画面の水平方向を基準にする。
- 値を増やすとカメラ側が画面右方向へ移動し、アンカーは画面上で左へずれる。
- YawまたはPitchを変更しても、同じPan Right値が表す画面内の横ずれを維持する。

### Pan Up

- 常に現在の画面の垂直方向を基準にする。
- 値を増やすとカメラ側が画面上方向へ移動し、アンカーは画面上で下へずれる。
- YawまたはPitchを変更しても、同じPan Up値が表す画面内の縦ずれを維持する。

### Yaw

- アンカーforwardは、プレイヤーPelvisが示すbody forwardの逆向きとする。
- `0`ではアンカーforwardの反対側、すなわちプレイヤー正面側から映す。
- `-180`または`180`ではプレイヤー背面側から映す。
- 値を増やすとアンカーright側へ周回する。
- Pan RightとPan Upで決めたアンカーの画面内位置を変えない。
- Editorでは`-180..180 degree`の範囲とする。

### Pitch

- `0`では注視中心と同じ高さから映す。
- 値を増やすと注視中心より上から、減らすと下から映す。
- Pan RightとPan Upで決めたアンカーの画面内位置を変えない。
- 真上と真下で操作方向が反転することを避けるため、Editorでは`-89.9..89.9 degree`の範囲とする。

### Distance

- 値を増やすと注視中心から離れ、減らすと近づく。
- Yaw、Pitch、Pan Right、Pan Upを変えない。
- Editorでは`0.1..100000 Skyrim unit`の範囲とする。

### Forwardを設けない理由

視線方向のForward移動はDistanceの変更と役割が重なる。ユーザーに同じ結果を生む設定を二つ提示しないため、独立したForward項目は設けない。

## 完全新規プリセットの初期値

`New preset`は次の値から開始する。

| 設定 | 初期値 |
|---|---:|
| Pan Right | `0` |
| Pan Up | `60` |
| Yaw | `0` |
| Pitch | `0` |
| Distance | `200` |

この初期値は、アンカーを画面中央より下に置き、プレイヤー正面側から水平に映す編集開始点とする。

## プリセット操作

### 選択

- 保存済みプリセットを保存順で一覧表示する。
- Dashboardで選択すると、現在のsceneでの状態とpreview開始対象を切り替えるが、cameraは変更しない。
- Editorで選択すると、その値を編集欄へ表示して直ちにプレビューする。
- 未保存変更がある状態で別のプリセットを選ぶ場合は、保存、破棄、編集継続のいずれかを選ばせる。

### New preset

- 完全新規プリセットを標準初期値から作成する。
- 既存IDと重ならない仮IDを提示する。
- 新規作成中はIDを編集できる。

### New from current camera

- 現在プレビュー中の構図を全項目そのまま複製し、別IDの新規プリセットとして開始する。
- 現在のcamera構図を取得できない場合は無効にする。

### Save

- 新規作成または既存プリセットへの変更を確定する。
- 未保存変更がない場合は無効にする。
- 最後に変更した数値が実際のプレビューへ反映されるまでは無効にする。
- ID重複、不正値、保存失敗では確定せず、理由を表示して編集中の内容を維持する。
- 保存に失敗しても、最後に正常だった保存済みプリセットを失わない。

### Cancel changes

- 既存プリセットの編集中は、編集欄とカメラを最後に保存した構図へ戻す。
- 新規作成中は編集中の内容を破棄し、保存済みプリセットの選択状態へ戻す。
- 未保存変更がない場合は無効にする。

### Delete

- 保存済みプリセットだけを削除できる。新規作成中は無効にする。
- 削除前に対象IDを示して確認する。
- 削除後にプリセットが残る場合は、残ったプリセットを明示的に選択してプレビューする。
- 最後の1件を削除した場合の動作は「プリセット0件」を参照する。

### Reload

- 外部で変更された保存済みプリセットを読み直す。
- 未保存変更がある場合は、保存、破棄、編集継続のいずれかを選ばせる。
- 読込に失敗した場合は現在の一覧と編集中の内容を維持し、理由を表示する。

### Close

- 未保存変更がある場合は、保存、破棄、編集継続のいずれかを選ばせる。
- editor用previewを終了し、進行を再開するscene cameraを通常の保存済みプリセット表示へ戻す。
- 同じ終了通知を複数回受けても、通常の保存済みプリセット表示への復帰は一度だけ行い、camera構図を繰り返し再適用しない。

## リアルタイム編集

- 5項目のいずれかを変更したら、保存を待たず、操作に追従してプレビューへ反映する。
- 編集中の構図について現在のsceneでの可視状態を更新し、使用可能か、見える参加者数はいくつかを表示する。
- 数値操作中は保存済みプリセットを書き換えない。
- 編集欄の値と最後に保存した値が異なる場合は、未保存状態であることを表示する。
- 無効な途中値はプレビューにも保存にも使用せず、最後に確認できた有効な構図を維持する。
- Editorはゲーム操作を遮断するためゲーム時間を停止するが、camera previewの更新は継続する。
- Editorへ入力しているmouse、keyboard、gamepad操作を通常のゲーム操作へ漏らさない。

## 編集できる条件

Preset dashboardはsceneとcamera制御の状態にかかわらず開いて状態を確認できる。数値の編集は、対象sceneのアンカーが確定し、camera制御を取得または維持して、選択した構図をpreviewできる場合だけ開始できる。現在のsceneで使用可能な保存済みプリセットがあることは、編集開始の条件にしない。

| 状態 | Dashboard表示 | Preview & edit | 値の編集 |
|---|---:|---:|---:|
| Player参加sceneでカメラ構図を表示済み | 可 | 可 | 可 |
| アンカー確定待ち | 可 | 不可 | 不可 |
| Playerが参加していないscene | 可 | 不可 | 不可 |
| 対象sceneがない | 可 | 不可 | 不可 |
| SmoothCamからcamera制御を取得できない | 可 | 不可 | 不可 |
| Improved Cameraがロードされている | 可 | 不可 | 不可 |
| カメラ構図を表示できない | 可 | 不可 | 不可 |
| camera所有権を失った | 可 | 不可 | 開いていれば即時ロック |
| 保存済みプリセットはあるが現在のsceneで使用可能なものが0件 | 可 | 可 | preview適用後に可 |
| プリセット0件だがpreviewを開始可能 | 可 | `Create & preview preset`を表示 | preview適用後に可 |
| ロード、new game、plugin reset | 可 | 不可 | 開いていれば即時ロック |

編集不可になった場合も、理由をcamera状態として表示する。他Modがcamera制御を持つ場合に、自動で何度も制御を奪い返そうとしない。

## 使用可能なプリセット0件

- 保存済みプリセットを一件以上読み込めていても、現在のsceneですべてのプリセットが参加者の可視条件を満たさない場合がある。
- この状態では保存済みプリセットを自動適用せず、通常のcameraを維持する。
- Dashboardでは各プリセットを現在のsceneでは使用不可として表示し、見える参加者数を示す。
- 対象sceneのアンカーが確定し、camera制御を取得可能なら、選択した既存プリセットの`Preview & edit`または新規作成へ進める。
- Editorでは、選択した既存プリセットまたは新規プリセットを編集用previewとして表示する。
- 編集用previewが実際に適用されるまでは値を編集できない。
- 編集用preview中は、現在のsceneにおける参加者の可視状態を確認できる。
- Editorを閉じた時点で使用可能なプリセットがあれば通常のscene cameraへ使用し、なければ通常のcameraへ戻る。
- 現在のsceneで使用できないことを、プリセットデータ自体の破損または恒久的な無効状態として扱わない。

## Editor表示中のscene進行

- Editor表示中はゲーム時間を停止するため、通常のscene進行、animation変更、scene終了は発生しない。
- camera制御と確定済みアンカーをEditorを閉じるまで維持し、数値変更に対するpreview更新だけを継続する。
- Editorはscene ID、参加actor、アンカーを編集対象として保持せず、5項目の数値だけをpreviewへ渡す。
- Editorを閉じるとscene進行を再開し、通常の保存済みプリセット表示へ戻す。
- ロード、new game、plugin reset、camera所有権喪失、カメラ構図の表示失敗では、時間停止中でも確認を待たず安全な復帰を優先する。

## プリセット0件

### Scene開始時から0件の場合

- 独自のカメラ構図を自動適用しない。
- Dashboardにプリセットが0件であることを表示する。
- Player参加sceneのアンカーが確定し、camera制御を取得可能なら、`Create & preview preset`を利用できる。
- `Create & preview preset`を実行すると、標準初期値の新規プリセットでpreview開始を試みる。
- previewが実際に適用されるまでは値を編集できない。
- camera制御の取得またはpreview適用に失敗した場合は編集をロックし、理由を表示する。
- 対象sceneがない場合はEditorを開けない。次のPlayer参加sceneで復旧する。

### Editorで最後の1件を削除した場合

- Editorを閉じるまでは、削除直前の最後に有効だったカメラ構図とcamera制御を維持する。
- 空の一覧から`New preset`または`New from current camera`を選べる。
- 新規プリセットを編集して保存すれば、通常のプリセット状態へ戻る。
- 0件のままEditorを閉じた場合はSmoothCamへ復帰する。

### Reloadの結果が0件の場合

- 最後の1件を削除した場合と同様に、Editorを閉じるまでは最後に有効だったカメラ構図を維持する。
- 新規作成せずに閉じた場合はSmoothCamへ復帰する。

## 未保存変更を伴う境界

- プリセット選択、New、Reload、Closeで現在の編集内容を失う可能性がある場合は、保存、破棄、編集継続を選ばせる。
- camera所有権喪失などの安全境界では確認待ちによって復帰を妨げない。camera操作を即時ロックし、編集中の内容はEditor内に残してよい。
- 安全境界後の編集内容は、次に編集可能なsceneでpreviewを再確認するまで保存できない。

## 完了条件

- Dashboardを開くだけではcamera制御またはゲーム時間の停止状態を変更しない。
- Dashboardで、各プリセットの現在sceneにおける状態、使用不可理由、見える参加者数、評価点数を識別できる。
- `Preview & edit`または`Create & preview preset`を実行した時だけ、ゲーム時間を停止して編集用camera previewを開始する。
- 各設定項目の変化が本仕様どおり画面へ現れる。
- 編集中の値に応じて現在sceneでの可視状態が更新される。
- カメラ構図を確認できない状態では編集できない。
- Editor中はscene進行を停止し、camera previewだけが数値操作へ追従する。
- Editor外のscene終了と安全境界ではcamera制御が残留しない。
- Editor終了通知が重複しても、通常のcamera構図への復帰を繰り返さない。
- プリセット0件から新規作成によって復旧できる。
- 現在のsceneで使用可能なプリセットが0件でも、既存プリセットの調整または新規作成によって復旧できる。
- 保存、破棄、取消、削除、Reloadのいずれでも、ユーザーの確認なしに未保存変更を失わない。
