# SKSE Menu カメラプリセット設定仕様

状態: **Preset dashboard・診断モード・使用不可候補のpreview編集実装済み／自動テスト・DLLビルド済み／ゲーム内確認待ち**

## 目的

SKSE Menuのカメラプリセットeditorで、ユーザーが何を設定でき、その値を変えると構図がどう変わるかを定める。また、editorを利用できる条件と、scene終了、camera制御喪失、プリセット0件などの境界動作を定める。

この文書はユーザーに見える設定と振る舞いだけを扱う。保存ファイルの形式、座標計算、内部状態、API呼び出し、実装手順は扱わない。

## Editorへの導線

- SKSE Menu FrameworkのMod Control Panelに`Sexlab Scene Camera > Camera Presets`を表示する。
- `Camera Presets`ページはPreset dashboardとし、保存済みプリセットの一覧、現在のsceneでの可視状態、camera状態を、camera制御を変更せずに表示する。
- 各プリセットには、現在のsceneで使用可能、現在のsceneでは使用不可、未評価のいずれかを、色だけでなく文言と記号でも表示する。
- previewを開始できない場合は、プリセットの可視状態とは分けてcamera状態と理由を表示する。
- 評価済みプリセットには、アンカーLOSの中心の成否と四隅の通過数を表示する。
- 使用不可のプリセットには、camera poseを作れない、中心遮蔽、四隅2本以上遮蔽、判定不能などの理由を表示する。
- Dashboardでプリセットを選択しても、ゲーム時間の停止またはcamera previewを開始しない。
- Dashboardには、再起動後も維持される`Debug mode`設定を表示する。
- `Debug mode`がONの間はcamera previewを開始せず、SmoothCam表示上で候補と可視判定を確認する。
- 選択したプリセットの`Preview & edit`を実行すると、ゲーム時間を停止してcamera previewを開始し、専用editorを表示する。
- プリセットが0件の場合は、`Create & preview preset`から標準初期値の新規プリセットをpreviewする。
- cameraを使った構図確認を開始できない状態では、previewを開始する操作を無効にして理由を表示する。一覧と状態の確認は妨げない。
- 保存済みプリセットのうち現在のsceneで使用可能なものがなくても、previewを開始可能なら使用不可のプリセットを選択してeditorへ進める。
- Improved Cameraがロードされている場合は非サポート構成としてeditorを無効にし、その理由を表示する。
- SKSE Menu Frameworkが利用できない場合も、保存済みプリセットを使う通常のscene camera機能には影響させない。
- SKSE Menu FrameworkまたはHUD表示を利用できない場合は`Debug mode`を有効化できず、保存値がONでも通常のscene camera機能には影響させない。

## Scene toolbar

- Player参加scene中は、現在適用中のプリセットを直接編集するためのScene toolbarを常時表示する。
- Scene toolbarには、現在適用中のプリセット表示名と、割り当てられたEdit hotkeyでそのプリセットを編集できることを表示する。
- Scene toolbarは表示専用とし、mouse cursorを表示せず、mouse入力を捕捉しない。
- `A` / `D`で現在適用中のプリセットが変わった場合は、Scene toolbarのプリセット表示名も追従する。
- `Debug mode`中はScene toolbarにデバッグ対象プリセットとSmoothCam表示中であることを示し、`A` / `D`をデバッグ対象の切り替えとして案内する。
- Scene toolbarに表示されたEdit hotkeyを押すと、別のプリセットへ切り替えず、現在表示している構図のプリセットをEditorで開く。
- Edit hotkeyを押した時点でゲーム時間を停止し、現在適用中のプリセットをcamera previewへ引き継ぐ。
- Editor内にも同じEdit hotkeyで閉じられることを表示する。未保存変更がある場合は通常のCloseと同じ確認を行う。
- 現在適用中のプリセットがない場合はその状態を表示し、Edit hotkeyを押してもEditorを開かない。
- Editor、Mod Control Panel、またはほかのゲーム操作を遮断する画面が開いている間は、重ねて操作できないようScene toolbarを表示しない。
- Scene toolbarは時間経過では非表示にしない。
- SKSE Menu Frameworkが利用できない場合はScene toolbarを表示せず、通常のscene camera機能には影響させない。

## Edit hotkey

- 初期割り当ては`F8`とする。
- Preset dashboardに、現在の割り当てと`Change edit hotkey`を表示する。
- `Change edit hotkey`の実行後に入力したkeyboard keyを新しい割り当てとして保存する。
- 割り当て待ちで`Escape`を押した場合は変更を取り消す。`Escape`自体はEdit hotkeyへ割り当てない。
- 割り当て待ちの間はEditorを開く操作を無効にし、割り当て完了または取消後に利用可能へ戻す。
- 保存した割り当てはゲームを再起動しても維持する。
- Edit hotkeyは、現在適用中のプリセットを編集できる時、またはEditorを閉じる時だけ入力を捕捉する。それ以外では同じkeyの入力を妨げない。
- 捕捉したEdit hotkeyと割り当て入力は、押下から解放まで同じ一回のkey操作として扱い、途中の入力だけをゲームへ渡さない。
- Edit hotkeyの押下後、Editorが開く前に別の操作遮断画面が開いた場合はEditorを重ねて開かない。

## 設定項目

Preset dashboardには通常のカメラ動作と診断表示を切り替える`Debug mode`を表示する。初期値はOFFとし、変更した値を保存する。ONの間は独自のカメラ制御を取得せず、`A` / `D`をデバッグ対象プリセットの切り替えに使う。

Editorには次の6項目を表示する。

| 表示名 | 変更時の構図 |
|---|---|
| `Pan Right` | カメラと注視中心を画面の左右方向へ移動する |
| `Pan Up` | カメラと注視中心を画面の上下方向へ移動する |
| `Yaw` | アンカーの周囲を水平方向に周回する |
| `Pitch` | アンカーの周囲を垂直方向に周回する |
| `Distance` | 注視方向を維持したまま、注視中心へ寄る、または離れる |
| `FOV Offset` | ユーザーの通常FOVを基準に画角を広げる、または狭める |

### Pan Right

- 常に現在の画面の水平方向を基準にする。
- 値を増やすとカメラ側が画面右方向へ移動し、アンカーは画面上で左へずれる。
- YawまたはPitchを変更しても、同じPan Right値が表す画面内の横ずれを維持する。

### Pan Up

- 常に現在の画面の垂直方向を基準にする。
- 値を増やすとカメラ側が画面上方向へ移動し、アンカーは画面上で下へずれる。
- YawまたはPitchを変更しても、同じPan Up値が表す画面内の縦ずれを維持する。

### Yaw

- アンカーforwardは、プレイヤーActorの水平前方の逆向きとする。
- `0`ではアンカーforwardの反対側、すなわちプレイヤー正面側から映す。
- `-180`または`180`ではプレイヤー背面側から映す。
- 値を増やすとアンカーright側へ周回する。
- Pan RightとPan Upで決めたアンカーの画面内位置を変えない。
- Editorでは`-180..180 degree`の範囲とする。

### Pitch

- `0`では注視中心と同じ高さから映す。
- 値を増やすと注視中心より上から、減らすと下から映す。
- Pan RightとPan Upで決めたアンカーの画面内位置を変えない。
- 真上と真下で操作方向が反転することを避けるため、Editorでは`-89.9..89.9 degree`の範囲とする。

### Distance

- 値を増やすと注視中心から離れ、減らすと近づく。
- Yaw、Pitch、Pan Right、Pan Upを変えない。
- Editorでは`0.1..100000 Skyrim unit`の範囲とする。

### FOV Offset

- ユーザーが設定している通常の三人称FOVを`0 degree`の基準とする相対値である。
- 値を増やすと画角が広がり、減らすと狭まる。
- Editorでは`-160..160 degree`の範囲とする。
- 実際に表示するFOVは`10..170 degree`へ制限し、基準FOVとの合計が範囲を越える場合は上限または下限で止める。
- シーンカメラを解放した時は相対値を解除し、ユーザーの通常FOVへ戻す。

### 相対値を採用する理由

通常FOVはゲーム設定とカメラModのユーザー設定に属する。プリセットが絶対値で上書きすると、その設定を無視し、終了時に復元すべき外部状態も増える。相対値ならユーザーの基準を維持したままプリセットごとの寄り引きを表せ、既存プリセットも`0 degree`として見た目を変えずに移行できる。

### Forwardを設けない理由

視線方向のForward移動はDistanceの変更と役割が重なる。ユーザーに同じ結果を生む設定を二つ提示しないため、独立したForward項目は設けない。

## 完全新規プリセットの初期値

`New preset`は次の値から開始する。

| 設定 | 初期値 |
|---|---:|
| Pan Right | `0` |
| Pan Up | `60` |
| Yaw | `0` |
| Pitch | `0` |
| Distance | `200` |
| FOV Offset | `0` |

この初期値は、アンカーを画面中央より下に置き、プレイヤー正面側から水平に映す編集開始点とする。

## プリセット操作

### 選択

- 保存済みプリセットを保存順で一覧表示する。
- Dashboardで選択すると、現在のsceneでの状態とpreview開始対象を切り替えるが、cameraは変更しない。
- Editorで選択すると、その値を編集欄へ表示して直ちにプレビューする。
- 未保存変更がある状態で別のプリセットを選ぶ場合は、保存、破棄、編集継続のいずれかを選ばせる。

### New preset

- 完全新規プリセットを標準初期値から作成する。
- 既存IDと重ならない仮IDを提示する。
- 新規作成中もIDは自動付与され編集できず、表示名を編集できる。

### New from current camera

- 現在プレビュー中の構図を6項目すべてそのまま複製し、別IDの新規プリセットとして開始する。
- 現在のcamera構図を取得できない場合は無効にする。

### Save

- 新規作成または既存プリセットへの変更を確定する。
- 新規・保存済みプリセットのName欄で表示名を編集できる。名前だけの変更も未保存変更として扱う。SaveはID、件数、順序、変更していない構図、選択を維持する。
- 表示名は空でない127バイト以内のUTF-8文字列とし、同名の別プリセットは許可する。一覧、選択欄、Scene toolbar、削除確認には表示名を使う。IDは表示のみで編集できない。
- 未保存変更がない場合は無効にする。
- 最後に変更した数値が実際のプレビューへ反映されるまでは無効にする。
- 空の表示名、不正値、保存失敗では確定せず、理由を表示して編集中の内容を維持する。
- 保存に失敗しても、最後に正常だった保存済みプリセットを失わない。

### Cancel changes

- 既存プリセットの編集中は、表示名を最後に保存した名前へ戻し、編集欄とカメラを最後に保存した構図へ戻す。
- 新規作成中は編集中の内容を破棄し、保存済みプリセットの選択状態へ戻す。
- 未保存変更がない場合は無効にする。

### Delete

- 保存済みプリセットだけを削除できる。新規作成中は無効にする。
- 削除前に対象の表示名を示して確認する。
- 削除後にプリセットが残る場合は、残ったプリセットを明示的に選択してプレビューする。
- 最後の1件を削除した場合の動作は「プリセット0件」を参照する。

### Reload

- 外部で変更された保存済みプリセットを読み直す。
- Reload操作はEditor内に置く。DashboardまたはDebug表示から直接Reloadする操作は提供しない。外部ファイルを変更しただけでは反映しない。
- 未保存変更がある場合は、保存、破棄、編集継続のいずれかを選ばせる。
- 読込に失敗した場合は現在の一覧と編集中の内容を維持し、理由を表示する。
- 成功して1件以上ある場合は、読込後の保存順で先頭のプリセットを編集対象に選び、その値をpreviewする。以前の選択IDが残っているかどうかでは選び直しを省略しない。同じIDの値が変わっていれば読込後の値を表示する。
- 成功して0件の場合は「プリセット0件」の規則に従う。Editor終了時の復帰先は、Reload前のIDを特別扱いせず、通常の編集終了規則で決める。

### Close

- 未保存変更がある場合は、保存、破棄、編集継続のいずれかを選ばせる。
- editor用previewを終了し、進行を再開するscene cameraを通常の保存済みプリセット表示へ戻す。
- 同じ終了通知を複数回受けても、通常の保存済みプリセット表示への復帰は一度だけ行い、camera構図を繰り返し再適用しない。

## リアルタイム編集

- 6項目のいずれかを変更したら、保存を待たず、操作に追従してプレビューへ反映する。
- 編集中の構図について現在のsceneでの可視状態を更新し、使用可否、中心の可視状態と四隅の可視数を表示する。
- 数値操作中は保存済みプリセットを書き換えない。
- 編集欄の値と最後に保存した値が異なる場合は、未保存状態であることを表示する。
- 無効な途中値はプレビューにも保存にも使用せず、最後に確認できた有効な構図を維持する。
- Editorはゲーム操作を遮断するためゲーム時間を停止するが、camera previewの更新は継続する。
- Editorへ入力しているmouse、keyboard、gamepad操作を通常のゲーム操作へ漏らさない。

## 編集できる条件

Preset dashboardはsceneとcamera制御の状態にかかわらず開いて状態を確認できる。数値の編集は、対象sceneのアンカーが確定し、camera制御を取得または維持して、選択した構図をpreviewできる場合だけ開始できる。現在のsceneで使用可能な保存済みプリセットがあることは、編集開始の条件にしない。

| 状態 | Dashboard表示 | Preview & edit | 値の編集 |
|---|---:|---:|---:|
| Player参加sceneでカメラ構図を表示済み | 可 | 可 | 可 |
| アンカー確定待ち | 可 | 不可 | 不可 |
| Playerが参加していないscene | 可 | 不可 | 不可 |
| 対象sceneがない | 可 | 不可 | 不可 |
| SmoothCamからcamera制御を取得できない | 可 | 不可 | 不可 |
| Improved Cameraがロードされている | 可 | 不可 | 不可 |
| カメラ構図を表示できない | 可 | 不可 | 不可 |
| Debug modeがON | 可 | 不可 | 不可 |
| camera所有権を失った | 可 | 不可 | 開いていれば即時ロック |
| 保存済みプリセットはあるが現在のsceneで使用可能なものが0件 | 可 | 可 | preview適用後に可 |
| プリセット0件だがpreviewを開始可能 | 可 | `Create & preview preset`を表示 | preview適用後に可 |
| ロード、new game、plugin reset | 可 | 不可 | 開いていれば即時ロック |

編集不可になった場合も、理由をcamera状態として表示する。他Modがcamera制御を持つ場合に、自動で何度も制御を奪い返そうとしない。

## 使用可能なプリセット0件

- 保存済みプリセットを一件以上読み込めていても、現在のsceneですべてのプリセットがアンカーLOSの条件を満たさない場合がある。
- 初期選択前は通常のcameraを維持する。適用中のプリセットがある場合は、全候補使用不能になっても現在の構図を維持し、自動では通常cameraへ戻さない。
- Dashboardでは各プリセットを現在のsceneでは使用不可として表示し、中心の可視状態と四隅の可視数を示す。
- 対象sceneのアンカーが確定し、camera制御を取得可能なら、選択した既存プリセットの`Preview & edit`または新規作成へ進める。
- Editorでは、選択した既存プリセットまたは新規プリセットを編集用previewとして表示する。
- 編集用previewが実際に適用されるまでは値を編集できない。
- 編集用preview中は、現在のsceneにおける中心と四隅の可視状態を確認できる。
- 保存済みプリセットをEditorで表示した後に閉じた場合は、可視条件を満たすかにかかわらず、そのプリセットをユーザーの明示選択として通常のscene cameraへ引き継ぐ。
- 新規プリセットを保存せずに閉じる、または編集対象が削除済みであるなど引き継げるプリセットがない場合は、編集開始前のプリセットへ戻し、使用不能でも維持する。編集前に選択がなかった場合、またはそのプリセットも削除済みの場合は通常のcameraへ戻る。別の使用可能候補を自動選択しない。
- 現在のsceneで使用できないことを、プリセットデータ自体の破損または恒久的な無効状態として扱わない。

## Editor表示中のscene進行

- Editor表示中はゲーム時間を停止するため、通常のscene進行、animation変更、scene終了は発生しない。
- camera制御と確定済みアンカーをEditorを閉じるまで維持し、数値変更に対するpreview更新だけを継続する。
- 外部からすでに発生したChange・終了通知は、時間停止とは別に[シーンカメラ手続き](scene-camera-procedure.md)の規則で受理する。Changeは期限後の候補再評価、一致する終了は確認より復帰を優先する。通常の追従と定期評価は停止したままとする。
- 現在の実時間30分のシーン上限はEditor中にも適用する。終了・reset・上限到達は「Editorを閉じるまで維持」の例外である。
- Editorはscene ID、参加actor、アンカーを編集対象として保持せず、6項目の数値だけをpreviewへ渡す。
- Editorを閉じるとscene進行を再開し、編集していた保存済みプリセットと保存後の構図を、現在の可視状態にかかわらず通常表示でも維持する。
- 編集対象が保存一覧に存在しない場合は編集前の選択へ戻す。編集前の選択がない、または削除済みなら通常のcameraへ戻る。
- ロード、new game、plugin reset、camera所有権喪失、カメラ構図の表示失敗では、時間停止中でも確認を待たず安全な復帰を優先する。
- 画面全体の終了通知は現在のEditorを閉じる。連続する終了通知で復帰を繰り返さないが、新しいEditorを開いた後に届いた画面終了を過去のEditor専用として除外する保証は持たない。

## プリセット0件

### Scene開始時から0件の場合

- 独自のカメラ構図を自動適用しない。
- Dashboardにプリセットが0件であることを表示する。
- Player参加sceneのアンカーが確定し、camera制御を取得可能なら、`Create & preview preset`を利用できる。
- `Create & preview preset`を実行すると、標準初期値の新規プリセットでpreview開始を試みる。
- previewが実際に適用されるまでは値を編集できない。
- camera制御の取得またはpreview適用に失敗した場合は編集をロックし、理由を表示する。
- 対象sceneがない場合はEditorを開けない。次のPlayer参加sceneで復旧する。

### Editorで最後の1件を削除した場合

- Editorを閉じるまでは、削除直前の最後に有効だったカメラ構図とcamera制御を維持する。
- 空の一覧から`New preset`または`New from current camera`を選べる。
- 新規プリセットを編集して保存すれば、通常のプリセット状態へ戻る。
- 0件のままEditorを閉じた場合はSmoothCamへ復帰する。

### Reloadの結果が0件の場合

- 最後の1件を削除した場合と同様に、Editorを閉じるまでは最後に有効だったカメラ構図を維持する。
- 新規作成せずに閉じた場合はSmoothCamへ復帰する。

## 未保存変更を伴う境界

- プリセット選択、New、Reload、Closeで現在の編集内容を失う可能性がある場合は、保存、破棄、編集継続を選ばせる。
- camera所有権喪失などの安全境界では確認待ちによって復帰を妨げない。camera操作を即時ロックし、編集中の内容はEditor内に残してよい。
- 安全境界後の編集内容は、次に編集可能なsceneでpreviewを再確認するまで保存できない。
- シーン終了・reset時は旧シーンのpreviewと編集終了後の復帰要求を取り消す。次のsceneが始まっただけでは下書きを自動適用せず、明示的にpreviewを開始して再確認する。

## 完了条件

- Player参加scene中に、現在適用中のプリセット表示名と編集開始方法をScene toolbarで確認できる。
- Scene toolbarでEdit hotkeyの実際の割り当てを確認できる。
- Edit hotkeyから、別のプリセットへ切り替えず現在適用中のプリセットを編集できる。
- 編集したプリセットを保存してEditorを閉じた後は、現在の可視状態にかかわらず同じプリセットが表示される。
- Edit hotkeyを変更して再起動した後も、その割り当てとToolbar表示が維持される。
- Toolbar表示中にmouse入力を捕捉しない。
- `A` / `D`でプリセットを切り替えるとScene toolbarの表示対象も切り替わる。
- 現在適用中のプリセットがない場合はScene toolbarから編集を開始できない。
- Dashboardを開くだけではcamera制御またはゲーム時間の停止状態を変更しない。
- Dashboardで、各プリセットの現在sceneにおける状態、使用不可理由、中心の可視状態と四隅の可視数を識別できる。
- Edit hotkey、`Preview & edit`、または`Create & preview preset`を実行した時だけ、ゲーム時間を停止して編集用camera previewを開始する。
- 各設定項目の変化が本仕様どおり画面へ現れる。
- 編集中の値に応じて現在sceneでの可視状態が更新される。
- カメラ構図を確認できない状態では編集できない。
- Editor中はscene進行を停止し、camera previewだけが数値操作へ追従する。
- Editor外のscene終了と安全境界ではcamera制御が残留しない。
- Editor終了通知が重複しても、通常のcamera構図への復帰を繰り返さない。
- プリセット0件から新規作成によって復旧できる。
- 現在のsceneで使用可能なプリセットが0件でも、既存プリセットの調整または新規作成によって復旧できる。
- 保存、破棄、取消、削除、Reloadのいずれでも、ユーザーの確認なしに未保存変更を失わない。
