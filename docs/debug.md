# 可視性評価のデバッグ表示

状態: **主要経路のゲーム内確認済み／境界ケース確認待ち**

## 目的

カメラ候補から参加者の各評価点までの可視判定と、遮蔽物へのhit位置がゲーム画面上の状況と一致することを確認できるようにする。

## 詳細設計

- 評価済みのワールド座標を、ゲーム画面上で線と点として確認できるようにする。
- 緑線は評価点まで見える経路、赤線は遮蔽物へ到達した経路、灰色線はhit位置から本来の評価点までを表す。
- 顔、胸、腰の評価点と、遮蔽物へのhit位置を区別できるマーカーで表示する。
- hit面の向きを確認できるよう、hit位置から法線を表示する。
- 遮蔽物へのhitから本来の評価点までの参考区間を、表示または非表示にできるようにする。
- 一度に表示するのは現在のカメラ構図だけとする。通常のscene cameraでは採用されたプリセット、editorのpreview中は編集中の構図を表示する。
- Preset dashboardには、デバッグ表示だけを前後の候補へ切り替える操作を設けない。
- 判定時に保存した結果を描画とログで共有し、デバッグ表示のために判定を再実行しない。
- シーン終了、再評価、ロード、新規ゲーム、reset時に古い表示データを破棄する。

## ログ

各評価結果について、プリセットID、参加者、評価部位、可視成否、hit位置、hit対象、hit割合を追跡できるようにする。通常ログには候補ごとの集計を出し、評価点ごとの詳細はデバッグ時だけ出力する。評価全体の集計には、実際に行った物理ray queryの総数と所要時間を出す。

## 対象外

- ゲーム世界へのデバッグ用オブジェクトの配置。
- 可視判定とは別の問い合わせを使った表示結果の再計算。
- 配布用ビルドでのデバッグ表示。

## 確認項目

- 見える経路、遮蔽物までの経路、遮蔽物から評価点までの経路を、それぞれ緑、赤、灰色で識別できる。
- 顔、胸、腰とhit位置を、それぞれ異なるマーカーで識別できる。
- hit位置から法線の向きを確認できる。
- 通常のscene cameraでは採用されたプリセットだけが表示される。
- Editorのpreview中は編集中の構図だけが表示され、値の変更へ追従する。
- Preset dashboardにデバッグ表示用の候補送り操作がない。
- hitから本来の評価点までの参考区間を表示する状態と表示しない状態を切り替えられる。
- 表示と詳細ログのプリセット、参加者、評価部位、結果、hit情報が一致する。
- 集計ログのray query数が、キャラクターのcollisionを透過するために追加で行った問い合わせを含む。
- シーン終了、再評価、ロード、新規ゲーム、reset後に古い線と点が残らない。
- 配布用ビルドでは線と点が表示されない。
