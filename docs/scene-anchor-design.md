# シーンアンカー

状態: **初期計算とシーン開始・終了境界を実装済み**

## 定義

シーンアンカーは、現在のアニメーションに対する撮影基準である。カメラプリセットの相対位置と相対回転をワールド座標へ変換する基準であり、アンカーからカメラ候補位置への raycast の起点にもなる。

## 要件

- 現在のシーンを代表する位置と向きを持つ。
- カメラプリセットの相対座標系として使える。
- カメラ候補位置への raycast 起点として有効である。
- 固定され，揺れない。

## 初期計算案

参加者それぞれの Pelvis node のワールド位置を取得し、その算術平均をアンカー位置とする。

```text
anchorPosition = average(participantPelvisPositions)
```

複数参加者の場合、アンカー位置からプレイヤーの Pelvis へ向かうベクトルを水平面へ射影し、アンカーの向きとする。

```text
direction = playerPelvisPosition - anchorPosition
direction.z = 0
anchorDirection = normalize(direction)
```

プレイヤーを含む全参加者の配置から向きを決めるため、複数参加者の場合にプレイヤー自身の向きの逆をそのまま使う方式は採用しない。

参加者が一人の場合はアンカー位置とプレイヤーの Pelvis が一致して方向を作れないため、プレイヤーの水平な向きの逆をアンカーの向きとする。多人数でも水平ベクトルの長さがほぼゼロになる配置では、同じ扱いを候補とする。

この計算結果が static collision 内にある場合の補正またはフォールバックは、別途検討する。

## ライフサイクル

```text
シーン開始
  -> 現在のアニメーションが反映された後にアンカーを計算

同じアニメーション中
  -> アンカーを維持

アニメーション変更
  -> 新しいアニメーションが反映された後にアンカーを再計算
  -> プリセット候補と raycast 結果も再評価

シーン終了
  -> アンカーを破棄
```

アニメーション変更イベントを受けた瞬間ではなく、新しい node transform がゲーム側へ反映された後に計算する必要がある。具体的なイベント境界と計算タイミングは今後調査する。

## 現時点で扱わないもの

- stage を独立した更新境界として扱うこと。
- 同じアニメーション中の移動や位置ずれに追従すること。
- static collision 内に計算されたアンカーの補正またはフォールバック。

これらは実際に問題が確認された時点で検討する。
